## 结论速览

- **推荐行动**:~~rehype-katex~~(已否决:项目此前试用过,LaTeX 覆盖度不足,维持 rehype-mathjax);~~启用 React Compiler~~(已落地:2026-09-03);~~db 脚本 `tsx → node`~~(已落地:2026-09-03,配合 `rewriteRelativeImportExtensions`)。
- **可考虑(1 项)**:`cheerio → node-html-parser`(低优先);~~`husky+lint-staged → lefthook`~~(已落地:2026-09-03)。
- **其余全部保留**:Hono / pino / drizzle / zod 4 / Vite 8(Rolldown)/ TS 7(tsgo)/ Tailwind 4(Oxide)等已是当前最快方案;Mastra / Electron / Remotion / Playwright 属架构绑定,无现实替代。
- **常规维护**:~~electron 43 → 44~~(已升级:2026-09-03);i18next 26.4.1 / react-i18next 17.0.13 / tsx 4.23.13 各落后 1 个 patch。
